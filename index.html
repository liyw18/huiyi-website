GOOD TO KNOW

你可能想知道。

支持 iPhone 吗？

当前提供 Android APK，支持 Android 7.0 及以上。暂未提供 iOS 安装版本。

下载后可以直接生成吗？

需要先在 APP 设置中填写自己的 DeepSeek API Key。API 服务的用量费用与额度由你的服务账号承担。

可以整场会议录音并自动转写吗？

当前使用手机系统语音识别，适合短句或要点。长会议请先取得转写文本，再通过 TXT / Markdown 导入。

草稿和纪要保存在哪里？

保存在当前手机的应用私有存储中。生成时输入会发送到 DeepSeek。清空记录或卸载前，可在设置中导出 JSON 或 Markdown 备份。

安装提示「未知来源」，怎么办？

这是直接安装 APK 时的系统提示。确认从本页下载后，按系统提示允许当前下载或打开文件的应用安装，再完成安装。不同手机的设置名称可能不同。

这是正式发布版吗？

当前 v1.3 为测试版安装包。功能已通过编译、单元测试及静态检查，仍需结合实际手机环境使用和反馈。AI 生成内容请核对后使用。
